# Подсказки NovellMaker Lua API

Создано редактором NovellMaker. Эта папка содержит только аннотации
LuaCATS / Lua Language Server: не импортируйте её через ui.import/game.run.
Редактор обновляет файлы в этой папке по команде «Подсказки Lua API».
Собственный код храните в зарегистрированных Lua-ресурсах.

Откройте папку проекта во внешнем редакторе с Lua Language Server.
Файлы @meta дают сигнатуры game.* v1, ui.*, события, слоты и геометрию.
Для LuaLS можно добавить в собственный .luarc.json (существующий не изменяется):

```json
{
  "runtime.version": "Lua 5.2",
  "completion.autoRequire": false,
  "runtime.builtin": {
    "basic": "disable", "bit": "disable", "bit32": "disable",
    "builtin": "enable", "ffi": "disable", "coroutine": "disable",
    "debug": "disable", "io": "disable", "jit": "disable",
    "math": "disable", "os": "disable", "package": "disable",
    "string": "disable", "table": "disable", "table.clear": "disable",
    "table.new": "disable", "utf8": "disable"
  },
  "workspace.library": ["Scripts/NovellMakerApi"]
}
```

`builtin` оставлен включённым: это определения базовых типов LuaLS (`string`,
`number`, `boolean`, `table`), а не доступ к стандартным функциям Lua в игре.
Остальные библиотеки отключены; поддерживаемые функции описывает library.lua.

Аннотации описывают два разных окружения: game.* и refs — сценарные ресурсы;
ui.*, refs, modules, audio и ограниченные math/string/table — обработчики компонентов
и их зарегистрированные модули. Наличие подсказки не открывает API в другом
окружении. refs, modules и audio заполняются GUI; произвольного файлового require нет.
audio.<имя> — ссылка на WAV у корневого Lua-обработчика; модули принимают её
аргументом. ui.play_audio(asset,group,loop,volume) возвращает ID источника,
ui.set_audio_volume задаёт его громкость, ui.stop_audio останавливает.
audio_result содержит audio_id/status/message. Источник принадлежит экземпляру,
очищается при закрытии; Master и громкость группы умножаются на громкость источника.
Полноценный language server не входит в движок и автоматически не устанавливается.

ui.log("info", "Открытие") пишет в ограниченный журнал с контекстом host.
Уровни info/warning/error, две строки, сообщение до 1024 UTF-16 единиц.
32 записи/8192 символов на загрузку или событие, превышения пропускаются со счётчиком.
В свойствах Lua «Журнал Lua F6» открывает файл профиля, обновляемый предпросмотром.
В автономной игре журнал находится рядом с profile.json в Games/<project-id>.
Файл содержит последние 256 записей; это диагностика, не сохранение игры.
Не помещайте секреты и личные данные в собственные сообщения.

F6 запускает неизменяемый снимок всех исходников. Сохранение внешнего файла
обновляет проверку редактора, но работающая VM продолжает прежний код.
Повторный F6 создаёт новые VM/кэш модулей; обработчики не переигрываются автоматически.

Полный справочник текущего кода в репозитории: `docs/lua-reference/index.md`.
Эти аннотации устанавливаются в проекты отдельно; наличие подсказки не меняет окружение VM.
