# Руководство движка для автора

[Оглавление Lua](index.md) · [Примеры](examples.md) · [Ограничения и проверка](compatibility.md)

NovellMaker — редактор и движок для **независимых проектов новелл**. Проект содержит сцены, тексты по языкам, персонажей, изображения, WAV, Lua-ресурсы, холсты интерфейса и авторские назначения ввода. Базовую новеллу можно собрать в GUI; Lua дополняет сценарий и позволяет писать интерфейсы/мини-игры. Это не одна встроенная игра и не набор обязательных игровых меню.

## Проект и рабочее пространство

Создайте проект, задайте название и основной язык, сохраните `.novell` в отдельную папку. ID проекта остаётся при переименовании и определяет профиль/слоты игрока. Формат — строгий JSON **v25**; миграции v1–v24 выполняются в памяти, исходный файл не переписывается до явного сохранения. Новая версия, неизвестные/повторные поля и неверные ссылки диагностируются. Чужие правки файла вне редактора не должны молча перезаписываться: используйте Save As при конфликте.

| Действие редактора | Клавиша |
| --- | --- |
| Создать / открыть / сохранить | Ctrl+N / Ctrl+O / Ctrl+S |
| Сохранить как / закрыть проект | Ctrl+Shift+S / Ctrl+W |
| Undo / redo | Ctrl+Z / Ctrl+Y |
| Обновить ресурсы и Git / запустить снимок | F5 / F6 |

Изменения отмечаются `*`; при закрытии можно сохранить/отказаться/отменить. Undo/redo сохраняет авторские связи; история ограничена 200 операциями, последовательный ввод одного поля объединяется. Текст Lua отменяется во внешнем редакторе, а не общей историей проекта.

### Реплики и лист записи

Для готового сценария используйте «Проект → Импорт персонажей и диалога…» или «Импорт…» во вкладке «Реплики»: CSV/TSV с настраиваемыми колонками и JSON v1 со сценами, персонажами, позами, переводами и необязательными WAV. Профили колонок и внешние ключи сохраняются в проекте v25; повторный импорт сохраняет внутренние ID, порядок и события существующих реплик. [Форматы, примеры и правила обновления](dialogue-import.md).

Во вкладке **«Реплики»** выберите язык сверху. В строках сцены можно редактировать текст и выбирать говорящего, включая рассказчика. ComboBox поддерживает клавиатуру; `Ctrl+Enter` в строке вставляет новую фразу ниже и переводит фокус в её текст. Номер показывает текущий порядок, ID и ключ перевода сохраняются при перестановке. «Вставить диалог…» принимает строки `Лена: Ты слышал?`; строка без двоеточия становится репликой рассказчика. Предпросмотр показывает разбор, одинаковое имя сопоставляется один раз для всей вставки. Неизвестные и неоднозначные имена требуют выбора персонажа либо рассказчика. Вся вставка отменяется одним Undo.

В колонке **«Озвучка»** можно выбрать уже импортированный звук или прикрепить/заменить PCM WAV кнопкой «WAV…» либо перетаскиванием **одного файла** на нужную строку. Формат: PCM 16 bit, mono/stereo, 8000–48000 Гц. Длительность берётся из WAV, имя файла видно в выборе и подсказке. ▶ воспроизводит один дубль через потоковый бэкенд runtime с громкостью Master/voice; «Стоп», смена фразы/языка/вкладки и запуск F6 прекращают прослушивание. Ошибка открытия выводится внизу таблицы. Импорт копирует файл в ресурсы проекта и сохраняет привязку по ID фразы и выбранному языку.

**«Без голоса»** означает намеренный отказ автора от озвучки на выбранном языке; установка снимает существующую запись этого языка. «Запись нужна» означает отсутствие привязки, а фильтр «Нужна запись» исключает фразы с отметкой «Без голоса». Назначение WAV снимает эту отметку. Есть фильтр по говорящему и счётчики; необязательная колонка «Эффект фразы» редактирует отдельный effect. Циклический sound остаётся в свойствах сцены на вкладке «Звук» вместе с общим микшером.

**«Лист…»** предлагает выбор **«Вся сцена / Строки по фильтру»** с количеством реплик в каждом варианте, затем сохраняет лист на выбранном языке в CSV (запятая) или TSV (табуляция), UTF-8 с BOM. Вариант по фильтру использует текущие фильтры персонажа и отсутствующей озвучки вкладки «Реплики». Порядок, номера фраз полной сцены, ID и язык сохраняются; пустой вариант по фильтру недоступен. Отмена выбора или сохранения не меняет файл. Поля: `Number, Speaker, Text, Language, LineId, Wav, Required`. Кавычки, разделители и переводы строк внутри текста экранируются; заголовки не переводятся. `Number` нужен только для чтения. `Wav` — предложенное имя `<LineId без дефисов>_<язык>.wav`; актёр сохраняет записи с такими именами в одну папку. Имя допускается менять в самом листе, сохраняя расширение WAV и не добавляя путь. `Required=false` исключает строку из импорта. Переводы для языка листа следует заполнить до отправки на запись.

**«Принять WAV…»** запрашивает возвращённый лист и папку файлов. Перед применением показываются совпадения, записи без изменений, отсутствующие файлы, замены, пропущенные строки и файлы вне листа; каждая строка имеет причину. Входящий WAV сравнивается по SHA-256 с ресурсом, уже назначенным этой фразе на этом языке. Совпадающие байты сохраняют прежний ID ресурса и не создают копию; кнопка применения считает только новые и заменяемые записи. При полном совпадении пакет не меняет проект, dirty-флаг или историю Undo/redo. Например, возврат папки из 30 WAV с одним изменённым дублем добавляет один ресурс. Старый изменённый дубль остаётся для Undo и по общим правилам каталога включается в экспорт, поэтому ресурсов будет 31, а не 60. Привязка идёт по `LineId + Language`, поэтому перестановка фраз во время записи допустима. Изменённый после экспорта текст отмечается предупреждением. Неизвестные ID, язык без текста у фразы, отметка «без озвучки», неверные/неоднозначные WAV пропускаются; корректные записи можно применить вместе. Дубли ключей/имён и неверная структура листа отклоняются целиком. Отмена предпросмотра не копирует файлы. Перед назначением проверяются скопированные байты WAV; изменившийся после предпросмотра файл или ошибка копирования отменяет весь пакет и удаляет его незавершённые копии.

Успешный пакет — одна операция Undo/redo. Undo восстанавливает привязки и каталог проекта; уже скопированные WAV остаются на диске для redo, как при обычном импорте ресурсов. Новое поле v24 `audio.voiceOmissions` хранит ID фразы и набор языков. Старые проекты получают пустые отметки; сохранения игрока и Lua API не меняются.

### Персонажи и анимация

Статические позы, персонажи из частей и покадровые клипы настраиваются в библиотеке «Персонажи». Раздел «Части и анимация» позволяет задать слои, родителя и pivot, изображения частей, клипы и ключи X/Y, угла, масштаба и прозрачности. Есть прокрутка времени и воспроизведение. Изменения применяются кнопками, входят в общий undo/redo, сохранение и восстановление редактора. **«Добавить готовый пример»** создаёт ресурсы, персонажа и сцену в текущем проекте; [готовый проект](../../examples/character-animation/example.novell) можно открыть отдельно.

Назначение позы запускает её клип по умолчанию. В событиях фразы действие **«Запустить клип персонажа»** выбирает персонажа, позу и клип; оно перезапускает локальное время, не показывает скрытого персонажа. Следующее назначение позы возвращает её клип по умолчанию. Показ уже видимого персонажа сохраняет фазу. F6 и экспорт используют один исполнитель и семплер; Load восстанавливает фазу без повторного выполнения команд. Покадровый клип имеет собственные длительности кадров, порядок, режим и число повторов. GIF импортируется в обычные PNG и такой же клип, включая композицию частичных кадров и disposal.

После явного запуска клипа добавьте «Ожидать → Завершение движений и клипов»: дальнейшие блоки продолжатся после всех движений и конечных клипов, включая конечные повторы. Бесконечные петли и клипы позы по умолчанию не задерживают очередь; звук этим барьером не ожидается. То же ожидание доступно через [game.wait_actions](scenario.md#game-wait-actions) в следующем Lua-блоке. Это последовательность событий фразы; общего таймлайна фрагмента со звуком пока нет.

Пошаговое редактирование, координаты, правила времени, лимиты и ограничения: [персонажи и клипы](characters.md).

## Автосохранение и восстановление редактора

Каждые 5 секунд, когда редактор не занят другой операцией, несохранённые данные записываются в отдельный восстановительный снимок в `LocalApplicationData/NovellMaker/Recovery`. Строка состояния показывает время последнего снимка или ошибку записи. Основной `.novell` автоматически не переписывается. Снимок сохраняет также ещё ни разу не сохранённый проект, незавершённые названия/параметры, тексты Lua и выбранные сцену/фразу. Запись выполняется через временный файл с атомарной заменой; контрольная сумма позволяет обнаружить повреждение.

После аварийного завершения при следующем запуске предлагается **восстановить**, **удалить снимок** или отложить решение кнопкой **«Позже»**. Восстановленная версия открывается в памяти с отметкой несохранённых изменений; основной файл остаётся прежним до явного сохранения. Снимки других работающих экземпляров редактора не предлагаются. Повреждённый или неподдерживаемый снимок сохраняется для разбора с диагностикой; другие снимки остаются доступны. Успешное сохранение, возврат undo к сохранённому состоянию или явный отказ от изменений удаляют соответствующий снимок; отмена закрытия сохраняет его.

Редактор проверяет внешние изменения `.novell` каждые 5 секунд, при возврате фокуса и F5. Можно оставить свою версию, сохранить её отдельно или явно загрузить версию с диска, отказавшись от текущих правок. Удалённый/повреждённый/недоступный файл загрузить нельзя. Перед сохранением дополнительно проверяется исходная версия файла, включая изменения форматирования; чужая версия не перезаписывается обычным сохранением. Если основной файл изменился после сбоя, восстановите снимок и используйте **«Сохранить как…»**. Отличающийся восстановленный текст Lua не заменяется автоматически рабочими `Scripts/*.lua`: сохраните восстановленную версию в другой каталог через Save As.

Граница восстановления — последний успешно записанный снимок: более свежие правки могут потеряться; занятая операция откладывает очередную запись. Снимок не является резервной копией ресурсных файлов, не восстанавливает физически удалённые изображения/звук и не сохраняет историю undo/redo или все открытые вкладки. Это отдельная система от игровых слотов и автосохранений игрока.

### Панели и обозреватель

Панели обозревателя, документов, экрана сцены, сведений/свойств и сообщений можно скрывать, изменять разделителями и закреплять перетаскиванием заголовка к краю другой панели; Escape отменяет перенос. Через «Вид → Панели» верните скрытую панель, через восстановление расположения — исходную компоновку. Локальный файл `LocalApplicationData/NovellMaker/workspace.json` не является данными новеллы. Отрыв панелей в отдельные системные окна не добавлен.

В параметрах проекта переключается логическая иерархия/папки и файлы. Сцены и персонажи в виртуальных папках остаются данными `.novell`, не отдельными сценарными копиями. В файловом режиме есть путь, переходы назад/вперёд/вверх, поиск текущей папки, миниатюры PNG/JPEG; навигация не обязана менять открытый документ. Для реальных файлов сначала сохраните проект. Ссылки каталогов не обходятся, `.git` скрыт. Git-маркеры отражают index/working tree/новые файлы/конфликты с учётом ignore; отсутствие Git и отсутствие репозитория различаются. F5 и возврат фокуса обновляют сведения. Редактор не предоставляет универсальный редактор всех типов файлов.

Стартовая страница доступна без проекта: создание/открытие, проверочный пример, последние 10 проектов из `recent-projects.json` локального профиля. Ошибка открытия не заменяет текущий черновик. Контекстное меню/F2 переименовывает Lua-ресурс с сохранением ID и физического пути. Перетаскивание зарегистрированного Lua на сцену добавляет вызов в начало сцены, на фразу — во время фразы, в область события — в выбранную фазу; исходник не перемещается. Чужие данные проекта отклоняются.

Удаление через Del/кнопки требует подтверждения; прямые ссылки очищаются с undo, строковые GUID внутри Lua автоматически не переписываются. Физическое удаление использует резервную копию в `NovellMaker/DeletedFiles` временного каталога; undo/redo текущего сеанса не перезаписывает внешние изменения. Открытый `.novell`, корень, `.git` и пути через ссылки защищены. Save As в другой каталог очищает историю файловых операций.

## Ресурсы и перенос проекта

Импорт PNG/JPEG копирует зарегистрированный файл в `Assets/Images/<id>.png|jpg`; исходник после импорта не нужен. До 64 МиБ сжатого файла, сторона 1..8192 пикселей, до 32 000 000 пикселей. Имя ресурса можно менять, ID/связи сохраняются. Библиотека даёт поиск, миниатюры и просмотр; сцене назначается статический задник. Неподдерживаемые форматы/отсутствующие/повреждённые файлы диагностируются. Отдельного Lua-загрузчика изображения по пути нет.

WAV импортируется в `Assets/Audio`; поддерживается только PCM signed 16-bit mono/stereo 8000–48000 Гц. RIFF должен быть целым, с одним fmt/data, корректными align/rate/длиной; до 1024 chunks, импортируемый файл до 2 ГиБ. Автоматического конвертера MP3/OGG нет. Назначения `sound` — фон сцены, `effect` — эффект фразы, `voice` — запись фразы по языку. Для voice другого языка автоматического fallback нет. Продолжение останавливает voice, effect доигрывает, sound остаётся; переход останавливает voice/effect, смена сцены заменяет sound; завершение/ошибка останавливает звук. Микшер содержит Master/sound/effect/voice с volume/mute; Lua источники описаны [отдельно](audio.md).

### Озвучка, fades и ducking

В F6 и автономной игре переключатели «Показывать прогресс озвучки» и «Показывать паузу и продолжение озвучки» управляют полосой/временем и кнопкой в нижней панели. Кнопка останавливает только voice текущей реплики; sound/effect продолжаются. Общая пауза/потеря фокуса удерживает сюжетный звук, а возвращение в игру сохраняет ручную паузу voice. Новая реплика начинает голос без унаследованной ручной паузы. Нет записи нужного языка, ошибка открытия или естественное окончание — «Нет озвучки», кнопка недоступна, прогресс сброшен. История и Lua-источники не подменяют прогресс текущей реплики. Статический образец оформления не запускает звук; отдельный дубль можно прослушать кнопкой ▶ в таблице «Реплики», а сцену целиком — через F6.

Позиция проходит `IAudioSource.Position/Duration → AudioService.Voice → runtime`. Длительность берётся из PCM-метаданных; позиция — из количества **воспроизведённых**, снятых MonoGame с очереди буферов. Шаг около 100 мс соответствует существующим потоковым блокам; это не таймер и не количество прочитанных/отправленных байтов. Очередь остаётся ограниченной тремя блоками на источник. Публичный [PendingBufferCount MonoGame](https://docs.monogame.net/api/Microsoft.Xna.Framework.Audio.DynamicSoundEffectInstance.html) задаёт число ожидающих блоков.

В параметрах проекта, «Воспроизведение звука», доступны:

- Плавное начало всех новых источников, с; затухание незакольцованных записей перед естественным концом и уход sound в сцену без фоновой дорожки, с. Естественное затухание следует реальной позиции PCM, с тем же шагом около 100 мс.
- Crossfade sound при смене сцен: исходящая и входящая дорожки играют одновременно с линейными огибающими. Ошибка открытия новой сохраняет предыдущую музыку и выдаёт диагностику. Переход на тот же ресурс также запускает новую дорожку.
- Приглушение sound при активном voice, включая Lua и повтор истории: множитель 0–1, время приглушения/восстановления. Пауза, mute/нулевая громкость voice и окончание/ошибка освобождают ducking. Несколько голосов удерживают его до последнего активного источника.

Все длительности конечные, 0–30 с; 0 означает мгновенное изменение. По умолчанию fades/crossfade равны 0, ducking выключен; его множитель 0,35, attack 0,15 с, release 0,3 с. Поле `audio.playback` — необязательное дополнение v21: прежние проекты загружаются с этими значениями. GUI поддерживает undo/redo и сохранение настроек; экспорт включает те же данные. Громкость источника умножается на огибающую, группу, Master и (для sound) ducking; профиль игрока при этом не переписывается. Fades заморожены у приостановленного источника. Продолжение/пропуск фразы, stop Lua, закрытие владельца, Reset/Load/завершение немедленно освобождают соответствующие источники, не дожидаясь хвостов. Load запускает фон сцены заново и не переигрывает voice/effect, точная позиция звука в слот не записывается.

Lua-ресурсы хранят снимок текста внутри проекта и рабочие UTF-8 `Scripts/<id>.lua`. Создание/импорт/открытие/ссылки — в обозревателе и свойствах; двойной щелчок открывает выбранное внешнее приложение. Пользовательская настройка пути приложения и открытия при создании — `LocalApplicationData/NovellMaker/code-editor.json`; команда запуска не задаётся проектом. Аннотации LuaCATS можно установить в `Scripts/NovellMakerApi` для внешнего редактора; они являются подсказками, не подключаемыми библиотеками. Не исполняйте game.lua/ui.lua/library.lua из аннотаций. [Ресурсы и модули](modules.md), [F6 и актуальность кода](execution-model.md).

Save As переносит зарегистрированные изображения/WAV/скрипты и сохраняет ID. Отличающиеся целевые файлы не перезаписываются молча. Удаление Lua-ресурса из библиотеки оставляет рабочий файл на диске; физическое удаление через обозреватель поддерживает backup/undo. Незарегистрированные файлы рядом с проектом не становятся ресурсами экспорта. Для резервной копии рабочего проекта переносите `.novell` вместе с ресурсными папками и актуальными Lua-файлами.

## Фразы, персонажи и сценарий

Создайте сцену, добавьте фразы, заполните текст и говорящего. У фразы сохраняются независимые переводы; переключение языка редактирует выбранный перевод. При отсутствии текста игрового языка используется основной язык с диагностикой. Копии получают новые ID/ключи локализации. Переименование и перестановка сохраняют ссылки.

Персонаж имеет набор состояний со стабильными ID и изображениями, одно исходное состояние. Выбор говорящего показывает его; другие остаются до скрытия. Состояние скрытого персонажа можно подготовить без показа. Размещение задаётся у фразы отдельно для любого персонажа: перетаскивание, точные x/y, масштаб, слой, быстрые позиции и возврат к автоматике. Escape отменяет перетаскивание. Сценарное размещение — доли сцены с нижней центральной опорой и масштабом к fit 360×560; это другая система, чем пиксели UI. [API персонажей](scenario.md).

Текстовые цвета: `§#RRGGBB` задаёт цвет, `§r` сбрасывает в базовый CSS, `§§` выводит §. Неполный/неизвестный код показывается буквально. Палитры §0–§f, управляющей жирности и HTML нет. Имя говорящего выводится отдельно.

Вкладка «Скрипт» показывает карточки блоков и вызовов Lua, привязанные к «До фразы», «Во время фразы», «После продолжения», а также началу/концу сцены. «Свойства и события» открывает боковую панель без потери документа/текста. Добавление/удаление/перемещение — контекстное меню. Порядок блоков внутри события последовательный; wait задерживает последующие команды. Движения могут идти параллельно очереди, независимого параллельного Lua-стека нет.

Доступны GUI-блоки показа/скрытия/состояния/размещения/движения, ожидания, строковые переменные/условия, выборы, переходы к фразам, вызов Lua и запуск/ветвление результата мини-игры. GUI-переход выбирает фразу и сам получает правильный LineEntry; в низкоуровневом game.choice action — скомпилированная команда, не GUID фразы. Для обычного выбора используйте GUI, чтобы не вычислять внутренний ID вручную. Не существует Lua-функции вычисления LineEntryId.

Статический экран редактора следует выбранной фразе и показывает размещение/показ/состояния. Он не продолжает ожидание, не исполняет Lua и не загружает слот. Динамику/ветвления проверяйте F6. Линейный проект без блоков может начать F6 с выбранной фразы и восстановить простые команды; в сцене с блоками выбор поздней реплики начинает исполнение с её LineEntry, включая BeforeLine. Для первой фразы F6 сохраняет обычный старт со SceneStart. Импортированный поток по F6 начинается с начала. «Назад» автора — выбор соседней фразы; в самостоятельной игре rollback/seek отсутствует.

**Отладка прохождения.** В сцене откройте «Отладка…», выберите начало сцены, реплику, привязанный блок или действие импортированного потока. Введите исходные сюжетные переменные, например `{"trusted": "yes"}`, и нажмите «Запустить с параметрами». Предпросмотр начинает новый сеанс сразу в выбранном месте. В поле результата мини-игры можно ввести `null` или объект, например `{"SceneId":"<ID сцены мини-игры>","Result":{"Phase":"Completed","Data":{"score":1},"Message":""}}`. Данные победы должны соответствовать схеме результата этой мини-игры. Предыдущие блоки, позы и история чтения не восстанавливаются. Для повторной проверки дайте набору имя и нажмите «Сохранить точку». Точки хранятся локально для проекта и сцены, привязаны к ID и используют текущую версию сценария. Повторное сохранение под тем же именем обновляет точку.

Панель показывает текущие переменные, фактическое и ожидаемое значения проверенного условия, выбор игрока и цель перехода. «Взять состояние прохождения» копирует переменные и последний результат мини-игры в параметры точки. Повреждённые файлы точек отображаются отдельно в том же списке. Выберите повреждённую запись для просмотра причины и удаления файла.

Для условий `if` и `elseif` сценарного Lua журнал показывает имя скрипта, номер строки, фрагмент условия и фактическое значение true/false при выборе ветки. Трассировка ограничена 4096 шагами VM и 63 записями условий на вызов. При достижении предела исполнитель продолжает скрипт и добавляет отметку в журнал. Журнал хранит последние 2000 событий текущего запуска. После обычного F6 его также можно открыть кнопкой «Отладка…».


## Холст, диалог и интерфейс

У каждой сцены свой холст с узлами Container/Panel/Text/Button/Image/Area. Один корень, дочерними контейнерами служат Container/Panel. Используйте дерево и свойства, выделение на холсте, перемещение/resize, привязку спрайта импортом или перетаскиванием. Есть вписывание и zoom 50–200% с прокруткой. Изображение растягивается в локальный прямоугольник, затем наследует transform/tint/clipping; текст кнопки рисуется сверху. Area — интерактивная область. Неправильная геометрия/лимит не должны создавать частичную операцию undo.

Anchor/pivot, scale/отражение, rotation, opacity, color/order и clip_children работают в общем renderer и hit-test. Родительские флаги/opacity/tint/clipping влияют на потомков; больший order выше среди siblings, поддеревья рисуются согласованно. Подробные диапазоны: [компоненты](components.md), [квоты](limits.md#components). Очень большая подпись может не попасть в бюджет растеризации: host покажет диагностику, кнопка останется заливкой без текста; это не отмена Lua-пакета. Lua не меняет тип/картинку/имя узла произвольной таблицей; создавайте визуальные шаблоны в GUI и копируйте через ui.create.

Диалог — компоненты холста с read-only привязками **Panel, Text, Speaker**; legacy CssPanel сохраняет автоматическую CSS-компоновку. Проекция текущей фразы не исполняет сюжет. После ручной компоновки размеры/позиции определяет холст, стиль шрифта/краски/keyframes — CSS. Попытка ui.set_text у привязанного Text/Speaker может быть заменена текущим текстом host. Не используйте привязанный узел как произвольный label счётчика.

CSS проекта наследуется целиком, собственный CSS сцены заменяет его целиком, это не браузерный cascade. Поддерживается один селектор `.dialogue` и максимум один `@keyframes`, лист <=32768 символов. Черновик неверного CSS можно редактировать/сохранять с диагностикой; F6/экспорт требуют корректного снимка. Образец удерживает последний корректный стиль, runtime имеет диагностический fallback.

| Свойство CSS | Поддерживаемые значения |
| --- | --- |
| background-color, color, border-color | #rgb, #rrggbb, #rrggbbaa, rgba(r,g,b,a); RGB целые 0..255, alpha 0..1 |
| padding | 1..4 значения px по CSS-правилу, 0..8192 каждое |
| border-width, border-radius, width, min-height, left, bottom | 0..8192 px |
| font-size | 8..160 px |
| font-family | одно системное имя <=128, буквы/цифры/пробел/дефис/подчёркивание, кавычки допустимы |
| text-align | left / center / right |
| animation-name | имя единственного keyframes или none |
| animation-duration | 0..60 секунд в s/ms |
| animation-timing-function | linear / ease-in / ease-out / ease-in-out |
| animation-iteration-count | положительное число <=10000 (включая дробь) либо infinite |

Ключевые кадры: from/to или 0..100%, свойства opacity [0,1], transform translateX/translateY [-8192,8192]px и scale [0,100] либо none. Разные transform можно объединить пробелом; повтор функции в кадре — ошибка. Неуказанные компоненты кадра нейтральны (opacity=1, смещения=0, scale=1), отсутствующие крайние кадры добавляются нейтральными. Default duration=0, iteration=1, timing=linear; конечная анимация остаётся в конечном состоянии, дробный повтор — на соответствующей доле. Easing — собственные квадратичные функции, не браузерный cubic-bezier.

```css
.dialogue {
  background-color: rgba(24,28,34,0.92);
  color: #E6E7E9;
  font-size: 24px;
  padding: 20px 24px;
  animation-name: appear;
  animation-duration: 300ms;
  animation-timing-function: ease-out;
}
@keyframes appear {
  from { opacity: 0; transform: translateY(16px) scale(0.98); }
  to { opacity: 1; transform: translateY(0px) scale(1); }
}
```

Нет дополнительных селекторов/псевдоклассов, CSS-переменных, shorthand animation, transition, calc, em/rem, процентов размеров, @import/url, HTML/JavaScript/загрузки внешних ресурсов. Системный шрифт не упаковывается автоматически; его наличие у игрока отдельно проверяйте. Индикаторы/аудиокнопки/навигация задаются параметрами проекта, не CSS; образец не имитирует аппаратную позицию аудио.

## Действия кнопок, клавиши и меню

Кнопке/Area назначается одно действие. Штатное действие не дублируется click в Lua:

| Действие | Поведение |
| --- | --- |
| Lua | click своему on_event |
| Scene | переход к целевой сцене с запуском её сюжета; отменяет прежние ожидания/движения/pending; время/переменные остаются |
| Open | открыть холст целевой сцены поверх, не запускать второй сюжет |
| Replace | заменить слой; для основной сцены — переход |
| Toggle | закрыть верхний такой слой либо открыть его |
| Close / Back | закрыть собственный / верхний слой |
| Continue | продолжить только input-ожидание сюжета |
| Volume / Mute | изменить группу Master/sound/effect/voice; delta Volume [-100,100]% в GUI |
| Save / Load | quicksave |
| NewGame / MainMenu / EndSession | новый проход из Menu / возврат в назначенное меню / завершение окна |
| ContinueGame / ListSlots / SaveSlot / LoadSlot / DeleteSlot | сервисы слотов, с ID/названием по свойствам |
| None | не выполнять действие |

У слоя независимо задаются приостановка нижнего сюжета и блокировка нижнего ввода. Основной холст сам сюжет не ставит на паузу. В параметрах сцены можно назначить единственное **стартовое меню проекта**: оно показывает холст/фон и ui-обработчик без запуска фраз/сценарного Lua/сюжетного звука; только NewGame начинает прохождение. Без стартового меню запуск прямой в сцену. Успешная смена игрового сеанса очищает старые экраны/операции; профиль сохраняется.

Назначения клавиш — данные проекта, до 64 уникальных. Разрешены A..Z, F1..F12, Escape/Enter/Space/Tab/Left/Right/Up/Down; модификаторы сочетаний в этом GUI не добавлены. Для подробного физического ввода Lua включает input_events=true и получает [события клавиш](events.md). Не путайте это с созданием назначений проекта.

Пустой новый проект не получает готовых P/F9/F7/F8-меню. Встроенные редакторские примеры создают обычные редактируемые сцены/ресурсы/назначения; их можно изменить/удалить. Отдельный [пример проекта](../../examples/author-interface/README.md) содержит собственные меню. Tab/Shift+Tab и активация Enter/Space обслуживают компоненты; при отсутствии фокуса продолжение идёт сюжету, если не перехвачено. Escape закрывает верхний слой, без слоя — окно. Закрывающий ввод не должен продолжать нижний сюжет.

## Чтение новеллы

В параметрах холста нажмите **«Добавить кнопки чтения к сцене»**: появятся редактируемые кнопки «История», «Авто», «Пропуск», «Чтение». Повторное добавление не дублирует назначенные действия. Их можно переместить, оформить или назначить другим кнопкам через инспектор: **History, AutoRead, SkipRead, ReadingSettings**. Те же действия доступны назначениям клавиш проекта; встроенных обязательных горячих клавиш нет. Добавляйте кнопки к каждой нужной сюжетной сцене. Предпросмотр F6 и готовая игра используют один механизм.

Эта операция также добавляет обычные авторские сцены **«История реплик»** и **«Настройки чтения»** с Lua-обработчиками. В них редактируются компоненты, подписи, сообщения ошибок, изображения и геометрия. У History/ReadingSettings в инспекторе выбирается целевая сцена; повторный вызов закрывает верхний экземпляр. Для перевода шаблона измените Text-компоненты; служебные refs сохраните или обновите обработчик. История доступна через `ui.get_history`, голос — через `ui.replay_history_voice`; параметры чтения — через существующие `ui.get_settings`/`ui.set_setting`. [Шаблоны, API и миграция](history.md). Шаблоны не добавляются в пустой проект без действий чтения.

Первое действие «Продолжить реплику» (Continue, Enter/Space без фокуса на кнопке) во время появления текста раскрывает всю текущую фразу, следующее продолжает сценарий. Навигационные кнопки «Назад»/«Вперёд» и стрелки сохраняют переход на одну фразу в пределах разрешённой навигации. Скорость — 0–200 Unicode-знаков/с, 0 означает мгновенный показ; начальное значение 40. Цветовые метки не считаются знаками. Размер диалога измеряется по полному тексту, поэтому плашка не растёт при печати. Настройка применяется сразу и сохраняется в профиле.

Авточтение ждёт полного текста и задержки 0–30 с (по умолчанию 2 с); по умолчанию дополнительно ждёт реального окончания привязанной озвучки. Эту проверку можно отключить в «Чтении». Отсутствующий/неоткрытый голос не создаёт бесконечного ожидания. Пропуск идёт только по ранее прочитанным фразам, не чаще одной за кадр и с интервалом не менее 0,08 с; голос пропускаемых фраз останавливается обычным продолжением. Новый текст остаётся для ручного чтения. Ручное продолжение выключает активный режим.

Прочитанным становится текст, полностью раскрытый в активном игровом окне. Отметка содержит сцену, стабильный ID реплики, запрошенный язык и хеш текста; перестановка/переименование не сбрасывает её, изменение текста или языка требует нового прочтения. Отметки хранятся отдельно от авторских Data и слотов в профиле v4, до 10000 вариантов; при заполнении удаляется самая ранняя добавленная отметка. Ошибка записи диагностируется, до закрытия игры отметки остаются в памяти. Новая игра и загрузка старого слота не стирают прочитанное.

Оба режима выключаются на выборе, мини-игре, ожидании интерактивного предмета, ошибке, завершении и при открытии слоя UI. Они не выбирают варианты и не сокращают таймеры/анимации; ожидание Lua, потеря фокуса и загрузка изображений приостанавливают часы чтения. После выбора/мини-игры режим нужно включить заново.

История хранит последние 500 посещений реплик, включая повторы и переходы между сценами. Она открывается поверх игры с паузой и показывает текст/говорящего/язык посещения; длинные записи разбиваются на страницы. «Повторить голос» использует озвучку языка этого посещения, без fallback на другой язык и без запуска эффектов, Lua или сценарных команд. Повтор подчиняется Master/voice, останавливает предыдущий повтор и прекращается при закрытии истории; текущий сюжетный звук остаётся на паузе. При потере фокуса повтор тоже ставится на паузу. Это журнал чтения, возврата состояния сюжета через него нет.

Текущий GameSave v4 сохраняет историю посещений, введённую в v3, и фазу клипов персонажей. После успешной загрузки история заменяется историей слота, текущая фраза показана полностью, режим ручной, сюжетные команды/голос фразы не повторяются. GameSave v3 сохраняет свою историю; старые v1/v2 без истории загружаются с пустой. Чтение старого формата не отменяет проверки точной редакции проекта. Сохранять произвольную позицию печати и активный режим не требуется; неудачная загрузка оставляет живой сеанс без изменений.

## F6, слоты, настройки и диагностика

F6 запускает отдельное нативное MonoGame-окно со снимком несохранённого проекта, не сохраняет исходник автоматически. Повторный F6 заменяет собственный процесс предпросмотра. Изменения файлов обновляют диагностику, но не код/замыкания живой VM. При закрытии редактор завершает только свой preview.

Слоты содержат сюжет и разрешённую активную мини-игру, требуют точной редакции. Профиль содержит настройки и persistent строки, живёт независимо. Загрузка сначала полностью проверяет/готовит отдельного игрока в фоне и только успех заменяет сеанс без replay. Нет автоматического восстановления обычных UI-экранов/аудиопозиций/Lua-стека. Форматы/пути/операции: [слоты и профиль](session-and-storage.md). Условия сохранения мини-игры: [мини-игры](minigames.md).

Lua-журнал: игра `LocalApplicationData/NovellMaker/Games/<project-id>/lua-diagnostics.log`, F6 `.../Saves/<project-id>/lua-diagnostics.log`; [лимиты](diagnostics.md). Ошибка запуска игры — `Games/<project-id>/startup-error.log`, до чтения манифеста — `Logs/startup-error.log`. Каталог установленной игры может быть read-only; данные игрока пишутся в профиль. Ошибки системного загрузчика до .NET обрабатывает ОС.

## Экспорт папки и установщика Windows x64

«Сборка → Экспорт игры для Windows x64…»: выберите сюжетную стартовую сцену и новую папку результата. Экспорт берёт текущий снимок с актуальными Lua-файлами, проверяет проект/ссылки/CSS/модули/зарегистрированные изображения и WAV. Ошибка не публикует частичную сборку, готовая папка не перезаписывается. Проверки не доказывают корректность всех исполняемых ветвей Lua — это проверяйте F6/тестированием игры.

Игроку передайте **всю папку**, запуск `NovellMaker.Runtime.exe` двойным щелчком. Включены self-contained .NET 10, MonoGame/MoonSharp/SkiaSharp/SDL2/OpenAL, `game.json` v2, `game.novell` v25 и зарегистрированные ресурсы/лицензии. SDK/редактор/сеть для обычного запуска не нужны. Пути считаются от EXE, не cwd; `.git`, редактор и незарегистрированные соседние файлы не упаковываются. JSON/ресурсы доступны игроку, шифрования/защиты от изменения нет. В диалоге экспорта задаются версия игры (3–4 числа 0..65535) и необязательная ICO до 1 МиБ. На Windows название, FileDescription, ProductName и версия встраиваются в игровой EXE; выбранная ICO становится его ресурсом. При releaseCheck версия сборки обязана совпадать с currentVersion. Без ICO сохраняется стандартная иконка.

GUI использует подготовленный шаблон `ExportTemplates/win-x64`, не вызывает SDK/пересборку. Манифест шаблона `runtime-template.json` v1 проверяет RID/версии/capabilities/MVID/размеры/SHA-256/список deps/лицензии. Лишний файл, ссылка, повреждённая/несовместимая поставка отклоняются; хеши не являются цифровой подписью. Отсутствие шаблона даёт диагностику, обычное редактирование/F6 остаётся доступным.

«Сборка → Установщик игры EXE…»: тот же снимок, стартовая сцена, версия 3–4 чисел 0..65535, необязательная ICO <=1 МиБ, новый выходной EXE. При настроенном releaseCheck версия должна совпасть с currentVersion проекта. Один EXE содержит автономную игру; локальный NSIS 3.13/zlib/MUI уже входит в поставку редактора. Никаких загрузок/SDK при авторском экспорте. Одна версия и ICO применяются к игровому EXE, установщику, деинсталлятору и ярлыку. Ресурсы меняются только в копии apphost после проверки шаблона; исходный шаблон остаётся прежним. Пользовательская иконка в EXE встраивается на Windows; подпись готовой игры выполняется после экспорта.

Установка для текущего пользователя без повышения прав, по умолчанию `%LOCALAPPDATA%/Programs/NovellMakerGames/<project-id без дефисов>`, ярлыки меню «Пуск», запись HKCU. Папка должна быть пустой, в том числе в тихом режиме. Повторная установка того же ID требует удаления прежней; обновления поверх нет. Деинсталлятор проверяет ID-маркер/зарегистрированный путь и удаляет только известные файлы/ярлыки/запись; чужие файлы, непустые папки и все сохранения остаются. Занятые файлы диагностируются. Выходной EXE не перезаписывается; сбой NSIS не публикует частичный результат.

Подпись Authenticode, чистая VM без SDK, отдельная нативная проверка Linux/macOS и экспорт этих ОС не заявлены как выполненные. Мобильные платформы/Web в первоначальный обязательный объём не входят.

## Текущие границы

Нет файлового require/общего сцено-Lua с обратимым преобразованием карточек, постоянной сценарной VM/возобновления произвольного стека, произвольного rollback, произвольной сети/CLR/OS API автора, облака/совместной работы, встроенной платформенной системы достижений. Автосохранение редактора **реализовано** отдельными [снимками восстановления](#автосохранение-и-восстановление-редактора). Интерфейсы/слоты/настройки/мини-игры/модули/RNG/ограниченная библиотека/явная проверка выпуска **реализованы** в пределах этого справочника. Общий таймлайн фрагмента сцены со звуком, событиями и ожиданиями, расширенный аудиотаймлайн/MP3/OGG и экспорт Linux/macOS не реализованы. Ожидание конечных клипов персонажей доступно в событиях фразы и через [game.wait_actions](scenario.md#game-wait-actions).
