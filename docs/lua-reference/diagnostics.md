# Диагностика

[Оглавление](index.md) · [Модель исполнения](execution-model.md) · [События](events.md) · [Квоты](limits.md)

Контекст: ui-обработчик и модули, **включая вычисление исходника до возврата handlers**. В сценарном game `ui.log` нет. Правила каждой записи: [пакет](execution-model.md#batch), [lifetime](execution-model.md#lifetime), [квоты журнала](limits.md#diagnostics). Лог допустим в restore on_load.

Журнал независим от транзакции команд: сообщение, сформированное до ошибки, может быть опубликовано вместе с диагностикой ошибки; это не подтверждение commit state или вида. Host добавляет session/generation/owner/instance/scene/script/event/line; автор не подменяет эти поля. Кольцо содержит 256 записей, старые вытесняются. Не сериализуется в слот/state/профиль. Экспортированная игра пишет ограниченный журнал в свой каталог профиля, запись/ошибка файла не должна останавливать игровой кадр. В редакторе используйте диагностику Lua и путь к внешнему исходнику.

Изоляция означает отсутствие API файлов/CLR и ограничение worker, а не полную ОС-песочницу. Ошибки/превышение квот следует диагностировать, а не ловить pcall (его нет). Система не предоставляет lua print, assert или error; для проверки условий используйте ветвления и log, для бизнес-отказа — явное состояние/результат.

<a id="ui-log"></a>
## ui.log

Добавить сообщение в диагностический журнал Lua.

```lua
ui.log(level, message) -> nil
```

**Доступность:** ui при загрузке исходника, on_load/on_event, модуль, мини-игра; restore допустим.

**Аргументы и ошибки:** Ровно две точные строки. level: info/warning/error; message: <=1024 UTF-16. nil, другой уровень, длинная строка — ошибка, не усечение.

**Возврат:** nil.

**Эффект и ограничения:** Диагностический эффект не является игровой командой и не откатывается с игровым пакетом. До 32 записей и 8192 символов сообщений/вызов включая модули; избыточные корректные записи отбрасываются со счётчиком, не ошибкой. Доступна также при загрузке исходника и в restore. Общие [квоты](limits.md), [атомарность](execution-model.md#batch) и [lifecycle/сохранение](execution-model.md#lifetime) применяются, если здесь не указано исключение.

**Пример** (предусловия refs/ресурсов приведены в начале страницы; это фрагмент соответствующего обработчика, если не показан полный return):

```lua
ui.log("info", "Интерфейс открыт")
```
