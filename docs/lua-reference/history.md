# Авторские окна истории и чтения

[Оглавление](index.md) · [Игровые сервисы](session-and-storage.md) · [События](events.md#service_result)

«Добавить кнопки чтения к сцене» создаёт обычные сцены «История реплик» и «Настройки чтения», их компоненты, refs и Lua-ресурсы. Откройте эти сцены и редактируйте текст, положение, размеры, цвет, изображения, иерархию и кнопки теми же средствами, что другие меню. Подписи ошибок и состояний тоже являются Text-компонентами: для перевода не требуется менять C#. Служебные имена refs связывают шаблон с обработчиком; переименование/удаление ref требует соответствующей правки Lua.

У кнопок **History** и **ReadingSettings** выбирается целевая сцена. Назначение клавиши с таким действием открывает выбранную в инспекторе сцену. Повторный вызов закрывает её, если она сверху. Можно назначить другой авторский экран или использовать обычные Open/Toggle. Пауза и блокировка нижнего слоя задаются политиками сцены; шаблоны по умолчанию модальны и приостанавливают сюжет. Close/Back закрывают экземпляр.

Настройки чтения используют [ui.get_settings](session-and-storage.md#ui-get-settings) и [ui.set_setting](session-and-storage.md#ui-set-setting): `text_speed`, `auto_delay`, `auto_wait_voice`. Шаблон выводит числа отдельно от подписей и переключает видимость авторских текстов «да»/«нет». Текст host.message не используется для пользовательских подписей; ошибка показывается собственным компонентом. Настройки остаются в профиле игрока, отдельно от проекта и слотов.

Проект v23 хранит цели этих действий. При открытии v21/v22 с прежними действиями без цели детерминированно создаются шаблоны и привязки; исходный файл меняется только при сохранении. v23 с отсутствующей или неверной целью отвергается. Проекты без этих действий не получают меню автоматически. Миграция меняет ревизию проекта; старые слоты другой точной ревизии не становятся совместимыми автоматически.

<a id="ui-get-history"></a>
## ui.get_history

Прочитать ограниченную страницу одного посещения из истории текущего игрового состояния.

```lua
ui.get_history(index?, page?, page_size?) -> request_id
```

**Доступность:** ui on_load/on_event, в том числе модули и мини-игры; в restore on_load сервисные эффекты запрещены. Источник — живой экземпляр холста текущего поколения; сценарный game API эту функцию не предоставляет.

**Аргументы и ошибки:** От 0 до 3 аргументов, лишние запрещены и без strict_arguments. Все переданные значения — конечные целые числа. `index`: 0..500, по умолчанию 0 (последнее посещение); остальные индексы однобазные, от старого к новому. `page`: 1..1000000, по умолчанию 1. `page_size`: 1..2048 Unicode scalar values, по умолчанию 700. Явный nil, строки, дроби и выход за диапазон — ошибка пакета. Допустимые индекс и страница при чтении ограничиваются фактически существующим диапазоном.

**Возврат:** Сразу GUID N `request_id`; позднее `service_result`, `operation="GetHistory"`, `history` с полями `count`, `index`, `page`, `pages`, `visit_id`, `scene_id`, `line_id`, `language`, `speaker`, `text`, `can_replay`. Числа индекса и страницы однобазные. При пустой истории первые четыре поля равны 0, ID отсутствуют, строки пустые, can_replay=false. При успехе message="ok"; настройки, slots и persisted к истории не относятся.

**Эффект и ограничения:** Только чтение, без выполнения Lua/команд сюжета, изменения времени, отметок прочитанного или позиции. До 500 посещений, включая повторы. Текст разрешается по языку посещения с fallback на основной язык проекта; цветовые метки удаляются. Страница содержит не более page_size scalars и 8 переводов строки; CR/CRLF нормализуются в LF. Суррогатные пары не разрываются; граница страницы может разделять составной графемный кластер. `language` ограничен 64 UTF-16, `speaker` — 256 UTF-16, сокращение сохраняет пары суррогатов. Это данные текущей ревизии проекта. `can_replay` проверяет привязку голоса именно языка посещения; наличие привязки не гарантирует успешного открытия файла. Подберите page_size и размеры Text-компонента вместе: API не измеряет авторский макет. В шаблоне page_size=500, Text переносится по ширине и выводится частями в пределах общих графических бюджетов.

**Пример** (нужен Text refs.body в авторском холсте):

```lua
local request
return {
  on_load=function() request=ui.get_history(0,1,500) end,
  on_event=function(e)
    if e.kind=='service_result' and e.request_id==request and e.history then
      request=nil
      ui.set_text(refs.body,e.history.text)
    end
  end
}
```

Одна сервисная команда на пакет; ответ требует живого источника/поколения и зарезервированного места. После закрытия, Load и смены сеанса устаревшие ответы не доставляются. В неприостанавливающем слое история может пополняться/вытеснять записи между запросами.

<a id="ui-replay-history-voice"></a>
## ui.replay_history_voice

Повторить озвучку сохранённого посещения без повторного исполнения реплики.

```lua
ui.replay_history_voice(visit_id) -> request_id
```

**Доступность:** ui on_load/on_event текущего живого холста. Воспроизведение разрешено только в фазе Playing; в restore on_load сервисные эффекты запрещены.

**Аргументы и ошибки:** Ровно одна строка GUID N из history.visit_id. Пустой/нулевой GUID, чужой тип и лишние аргументы — ошибка пакета. Корректный ID, отсутствующий в текущей истории (включая вытесненное посещение или другую загрузку), возвращает отказ сервиса.

**Возврат:** GUID N запроса; позднее service_result с operation="ReplayHistoryVoice", success и message-кодом: `ok`, `history_unavailable`, `voice_unavailable`. Произвольные ID реплик/аудиоресурсов не принимаются. Коды предназначены для выбора авторского локализованного текста, не для показа игроку напрямую. `ok` означает открытый источник, не обещает прослушивание до конца; отдельного события окончания эта функция не создаёт.

**Эффект и ограничения:** Использует озвучку языка посещения без fallback. Отдельный канал, громкость Master/voice, без эффектов реплики, возобновления музыки, Lua и сценарных команд. Новый успешный повтор заменяет предыдущий. Закрытие или замена исходного экземпляра, Load/новая игра прекращают повтор; потеря активности/покрытие другим холстом ставят его на паузу. Повтор привязан к конкретному экземпляру, а не имени/ID сцены. Применяются общие лимиты сервисного пакета и доставки.

**Пример** (фрагмент click-обработчика, row — ранее полученная e.history):

```lua
if row and row.can_replay and row.visit_id then
  request=ui.replay_history_voice(row.visit_id)
end
```
