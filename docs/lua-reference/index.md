# Lua-справочник NovellMaker

Практический справочник текущего кода на 31 октября 2026 года. Проект v20, Lua 5.2/MoonSharp 2.0.0, screen protocol v18. Запланированные функции не включены. Для начала прочитайте [модель исполнения](execution-model.md), затем [законченные примеры](examples.md). Возможности редактора, ресурсы и экспорт: [руководство движка](engine-guide.md).

## Пространства имён и данные

`refs`, `modules`, `audio`, `ui.null`, `math.pi`, таблицы handlers и событий, строки ID и handles **не функции**. Их контексты/сроки жизни описаны в [модели исполнения](execution-model.md#namespaces). Авторские функции модулей и примеров не становятся API движка. Ни весь Lua, ни вся стандартная библиотека MoonSharp не подключены.
