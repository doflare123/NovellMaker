## Платформы и форматы

Основная платформа 0.1 beta — Windows x64. Поставка редактора включает автономный
предпросмотр, Windows-шаблон игры и NSIS для сборки установщиков без SDK.
Linux x64 собирается отдельно как экспериментальная поставка редактора; статус
её нативной проверки указан в [описании выпуска](../RELEASE-0.1-beta.md).
Экспорт новелл и установщики Linux/macOS в интерфейсе не реализованы.

Формат проекта — JSON v25, сохранения игры — v4. Старые проекты v1–v24
мигрируют при открытии и записываются в новом формате только при сохранении.
Ресурсы используют относительные пути; переносите всю папку проекта.

## Ресурсы, сцены и чтение

- Звук: PCM WAV 16 bit, mono/stereo, 8000–48000 Гц. MP3/OGG не поддерживаются.
- Голосовой курсор отражает потреблённые аудиобуферы с шагом около 100 мс;
  позиция внутри записи не сохраняется в слот.
- Персонажи: статические позы, части с иерархией и ключами, покадровые клипы,
  импорт GIF. Деформация сетки, IK и импорт Spine отсутствуют.
- Общего таймлайна фрагмента сцены со звуком и событиями нет.
- CSS диалога поддерживается в явно описанном подмножестве, без совместимости
  со всем браузерным CSS. Наличие глифов зависит от используемого шрифта.
- Переход на предыдущую реплику в авторском предпросмотре не является откатом
  переменных, побочных эффектов или произвольного Lua.

## Lua

Используется ограниченный Lua 5.2 через MoonSharp 2.0.0. Доступны только
зарегистрированные API и описанная [стандартная библиотека](standard-library.md).
Произвольные CLR, процессы, файловая система и сеть авторскому коду не открываются.
Модули выбираются по ID ресурсов; файлового `require` нет.

Сценарный вызов создаёт новую VM и возвращает целый проверяемый пакет команд.
Произвольный стек Lua не сохраняется. Интерфейсы и мини-игры восстанавливают
явное сериализуемое состояние. Расширенные Lua-анимации персонажей и вращение
статических спрайтов не реализованы; перемещение и масштаб доступны через `game.move`.

На Windows worker ограничен Job Object 256 МиБ и управляемой кучей 64 МиБ.
На Linux/macOS есть ограничение управляемой кучи и таймаут; отдельной общей
квоты памяти процесса на уровне ОС нет. Остальные бюджеты описаны в [квотах](limits.md).

- Используйте `hover_enter`/`hover_leave`: `hover` допускается протоколом,
  но текущий runtime его не генерирует.
- Периодический `update` приходит мини-игре; обычный экран не получает таймер
  только из-за наличия этого события в протоколе.
- `is_restoring` остаётся true у восстановленного экземпляра. Ограничивайте
  проверку восстановления обработчиком `on_load`, чтобы не отключить дальнейшие события.
- Успешные сервисы, закрывающие экземпляр экрана, не отправляют ответ в его старую VM.

## Проверка поставок

Сборочные команды и обязательные проверки находятся в [инструкции сборки](../BUILDING.md).
Windows Delivery проверяет распакованный редактор, предпросмотр, автономную игру,
сохранения, чтение, анимации, голос и цикл установки/удаления. Пропуск обязательного
случая блокирует допуск. NativePortability проверяет runtime на текущей ОС;
это отдельная проверка, которая не подтверждает экспорт игры для этой ОС.

Автоматические проверки графики и аудиотракта не заменяют прослушивание на
оборудовании и проверку на чистой машине. Отчёты тестов, PNG и журналы сборки
хранятся в генерируемых артефактах, отдельно от авторского справочника.
