# Пример авторского интерфейса

Откройте `example.novell` в NovellMaker и запустите первую сцену через F6.
Это самостоятельный редактируемый проект: изображения, сцены и Lua-файлы находятся
в этой папке. Runtime не создаёт его интерфейс и не знает имён этих сцен.

- P переключает авторское меню; «Звук» открывает другую обычную сцену поверх него.
- F9 переключает сцену настроек звука. Кнопки используют общие команды Volume/Mute
  с выбранной аудиогруппой; кода готового микшера в runtime нет.
- F7/F8 назначены на сервисы сохранения/загрузки только в этом примере.
- Lua-ресурс `example-menu.lua` реализует on_load/on_event через ui.* и собственные refs.
- В v15 скрытый шаблон подписи создаёт живой экземпляр через `ui.create`, получает
  собственные угол/цвет/прозрачность и удаляется через `ui.remove` при закрытии.
  В инспекторе можно менять anchors/pivot, родителя, порядок и clipping поддерева.
- Фразы и блоки первой сцены показывают движение, ожидание щелчка, ветвление и слоты.

Меняйте компоненты и обработчики, назначайте клавиши в инспекторе сцены или удаляйте
эти сцены целиком. Новый пустой проект не получает ни этих ресурсов, ни назначений.
Исходник сборки данного модуля из публичного API данных:
`src/NovellMaker.Editor/Examples/ExampleInterfaceModule.cs`.
