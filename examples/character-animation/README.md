# Персонаж из частей

Откройте `example.novell` в NovellMaker. Выберите сцену «Пример · персонаж из частей» и нажмите F6. Первая и третья фразы используют тело/голову/руку с иерархией и ключами; вторая — четыре PNG-кадра с индивидуальными длительностями.

В библиотеке «Персонажи» выберите «Механик → Из частей». Меняйте pivot/родителей/ключи через «Части и анимация», применяйте изменения, проверяйте локальным воспроизведением и новым F6. Для проверки восстановления используйте сохранение и загрузку предпросмотра F7/F8. У автономной игры клавиши задаются данными проекта; в этом примере назначены F7/F8. Экспортируйте сцену через меню «Сборка» в новую папку Windows x64.

Справочник: [персонажи и клипы](../../docs/lua-reference/characters.md). Примерные PNG созданы процедурно в `ExampleCharacterAnimationModule`; внешних ресурсов и Lua для анимации нет.
